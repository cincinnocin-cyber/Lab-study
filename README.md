Science Study v3: exactly 1,200 GCSE science multiple-choice questions, 50 for each of 24 topics.

## UI update
Mobile-first card layout inspired by modern science quiz apps, with rounded cards, progress bars, subject tiles, gradient actions and a dedicated AI Tutor screen.


## Official Mark Schemes
The app now links to official GCSE past-paper and mark-scheme resources from AQA, Pearson Edexcel and OCR. It does not redistribute copyrighted exam-board PDFs.
